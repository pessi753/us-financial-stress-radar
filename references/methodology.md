# 计算口径 v1.0.0

## 清洗、日期与单位

FRED API observation_start 默认 2019-01-01，observation_end 与 realtime_start/realtime_end 均为 as-of。日内只保存实际抓取时间；历史日期 vintage 并不提供当晚具体时分的可得性保证。周频 H.8 等有发布延迟，as-of 不意味着观测是当日。

`.`、非有限数和无效日期丢弃；未来观测丢弃；重复日期最后一个有效值优先。分析日频数据时排除周末，包括 ICE 月末可能产生的周末估值；原始缓存仍保留。不同序列作差只在日期交集上计算，不前向填充。

百分数相减得到百分点，再乘100为 bp；1bp=0.01个百分点。利率/OAS 的 level 保持百分数；delta 转 bp。派生利差 level/delta 都是 bp。存量 level/delta 保持百万或十亿美元，指数保持点数。

D 表示按观测日期排序后 1/5/20/60 个有效工作日观测步数，通常对应交易日，但不保证等于完整交易所日历；有小缺口时可能跨更多日历日。参照点与最新点相距超过 ceil(n×7/5)+5 个日历日，delta 为 N/A。周频不计算 D，不把最新一周变化贴成 1D；另报 1/4/13 个周观测差，最大允许 7n+3 天。截止日到观测日过期阈值：日频5天、周频14天，H.8存款和信贷18天。阈值是宽松的数据质量门槛，不是官方发布日历。

## 水平统计与压力特征

每个指标以自己的最新观测日回溯1096天，排除最新值作为基线。至少126个日频或52个周频历史点才计算 Z-score/percentile 和评分；这是最低样本要求，不承诺都有完整三年。

- Z=(当前水平−历史均值)/样本标准差；标准差接近0则 N/A。
- P=100×(低于当前值的样本数+0.5×等于当前值的样本数)/样本数。并列值取中秩。
- 中位数和P90用线性插值分位，JSON保留可得样本数与窗口边界；不把窗口叫全历史。
- Score=压力特征的历史P，不是 z 的概率映射。
- 大部分指标压力特征=level×direction。越高越紧为+1；期限差以−1刻画倒挂。
- 准备金/存款/银行信贷使用 `−100×(本期/四周前−1)`，避免对长期增长的存量简单排名；四周间隔须25–31天。这些指标表格里的水平 Z/P 与其 Score 不是同一特征。
- 趋势对压力特征计算日频20步/周频4步变化。超过 registry 的 epsilon 为↑，负向为↓，其余→；↑表示压力特征上行，不总是原始值上升。

银行存量下降并不总是风险，曲线陡峭化也不总是改善，实际利率下降可能反映避险。这些代理量的模型风险在 registry 单列。相对分位也可能在平静年代对小变化给高分，需结合绝对值、变化幅度和 cross-confirmation。

## 分级和聚合

normal <50；watch 50–<75；stress 75–<90；severe ≥90。是版本化启发式配置，不是经校准的经济危机门槛，未宣称预测能力。

模块内按 registry.weight 加权；派生 CCC-BB/HY-BBB 各0.5，其他信用指标各1。Market 中 VIX权重1、NFCI/STLFSI各0.5。其他模块内各1。模块有效权重至少50%才出分；同时显示覆盖率。缺失项在可用模块内部重分配权重，因此覆盖变化可引起分数变化，跨日比较须先看覆盖情况。

总分=Funding×25%+Credit×30%+Banking×20%+Market×15%+Macro×10%。五模块均可计算、加权覆盖≥80%才给总分；不把缺失模块重新分配给其他模块。过期、缺失、备用缓存或历史不足的指标不参与评分。高分和数据不足分别表达。

## Cross-confirmation 与传导路径

指标 active=Score≥75且压力趋势↑。高位横盘不满足“继续恶化”规则，但仍保留高分，不能据此说没有压力。

- Funding：SOFR-EFFR 与 SOFR-IORB 均 active，作为一个资金市场证据。
- Credit：HY 与 BBB 均 active，作为一个信用市场证据。
- Banking：主要信贷、准备金、存款、银行信贷中至少两项 active。
- Market：VIX active；NFCI/STLFSI不另计，因为内含其他市场信息。
- 至少两个独立模块成立：cross_market_pressure。
- Funding、Credit、Banking 同时成立：systemic_pressure_confirmation。它是压力共现信号，不能称为危机预告。
- 信号未知时保留三态逻辑，不把未知转成False。单个模块成立但其他关键模块未知时返回数据不足。

CCC→HY→BBB→Funding→Banks 逐节点显示 active/未满足/未知，检测信用尾部到广泛融资与银行的共现。不是统计因果模型，也不推断先后次序；周频和日频观测不同步，实际传导也不一定遵循这条路径。本版没有历史事件先后排序或危机预测回测。

## 历史参照

2020-02-01至2020-06-30、2023-03-01至2023-05-31分别作为疫情和银行压力观察窗口。实际覆盖需≥预计观测数80%，首尾缺口不超过10天，才报告原始水平在压力方向上的窗口极值（不是压力Score极值）。否则 N/A，不硬编码记忆中的危机值。

自2026年4月起部分ICE序列在FRED仅保留约三年，当前无法覆盖2020且可能不覆盖2023窗口；SOFR-IORB亦受IORB起始时间影响。不要将不完整窗口的极值冒充整个事件峰值。本版没有长期授权数据库。
